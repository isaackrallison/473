# PML Reading Labs

Landing page for my interactive study guides for Kevin P. Murphy's *Probabilistic Machine Learning: An Introduction* (BYU CS 473).

**Live:** https://isaackrallison.github.io/473/

Each lab lives in its own repo and is served at `isaackrallison.github.io/<repo>/`. To add a lab, append an entry to `LABS` in `index.html`.
